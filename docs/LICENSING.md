# Licenciamiento

PULSO incluye Essentia.js 0.1.3 y sus artefactos WASM bajo AGPL-3.0. Este repositorio no
elige una licencia para el código propio.

Antes de distribuir una versión que enlace o incluya Essentia, hay dos opciones principales:

1. Publicar el conjunto bajo una licencia compatible con AGPL-3.0 y cumplir sus obligaciones,
   incluyendo ofrecer el código fuente correspondiente y conservar los avisos de copyright.
2. Sustituir Essentia por una implementación propia de tempo (o una dependencia con licencia
   compatible con el producto) y revisar nuevamente las obligaciones de distribución.

La decisión queda pendiente del mantenedor. No se debe añadir un archivo `LICENSE` ni presentar
el proyecto como licenciado hasta tomarla. Los avisos de `public/vendor/` deben conservarse.
